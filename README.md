# Git Demo

这是一个简单的个人主页与在线简历示例项目，用于演示 Git 仓库初始化、分支开发、提交以及合并流程。

## 页面预览

- [个人介绍页](index.html)
- [章鱼哥简历](resume.html)

## 项目内容

### `index.html`

简洁的个人介绍页面，包含个人简介、技能标签和联系方式。

### `resume.html`

响应式个人简历页面，包含个人简介、项目经历、核心技能和联系方式，也支持打印为 PDF。

## 本地运行

无需安装依赖，直接使用浏览器打开 `index.html` 或 `resume.html` 即可查看。

也可以在项目目录启动一个本地静态服务器：

```bash
python -m http.server 8000
```

然后访问：<http://localhost:8000>

## Git 操作记录

本项目包含以下 Git 实践：

- 初始化 Git 仓库
- 创建并切换到 `resume` 分支
- 在分支中开发简历页面
- 将 `resume` 分支合并到 `master`
- 使用提交记录管理项目版本
